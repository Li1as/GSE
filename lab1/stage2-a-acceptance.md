## 本次实现与验证

- `mail_reader.py` 使用标准库，通过验证证书的 IMAP TLS 连接读取邮件；提供 probe/list/read/thread。
- EXAMINE 只读打开邮箱，BODY.PEEK 获取头部或正文，无 STORE、EXPUNGE 或发送逻辑。
- 解析 MIME 编码、纯文本/HTML 备用正文、附件元信息；原始 EML 和解析 JSON 保存在被忽略的数据目录。附件文件名不作为文件路径使用。
- 使用账号、文件夹、UIDVALIDITY、UID 构造快照身份；同 UID 在 UIDVALIDITY 改变后不会覆盖旧身份。
- 关联 References/In-Reply-To/Message-ID 候选，不仅凭相同主题关联。当前只扫描当前文件夹最近至多 100 封的头部，跨目录和完整会话后置。
- 本地凭据权限 600，配置被 Git 忽略；示例不含账号和密码。认证错误不输出原始服务器异常，不自动重试。

执行 `python3 -m unittest discover -s lab1 -p 'test_*.py' -q`，48 项全部通过：原阶段一 40 项，加本阶段 8 项。新增测试覆盖中文 MIME 与附件、HTML 转文本、只读 PEEK、超大邮件拒绝、非法 UID、认证错误脱敏与不重试、会话候选关联、快照身份和文件权限。

## 真实验收操作清单

1. 用户扫码登录网页，开启 IMAP，生成客户端专用密码并更新本地 `mail.local.json` 的 password 字段。若学校管理员限制客户端访问，应保留错误并联系服务支持，不尝试绕过验证。
2. 执行 probe，要求退出码 0；执行 list，核对真实邮件主题、时间、UID。
3. 选定一封可用于验收的邮件，记下网页中的已读/未读状态，执行 read，核对正文和附件元信息、原始 EML 与 JSON 快照，再刷新网页确认状态未改变。
4. 对有真实往来的邮件执行 thread，核对候选关系；若父邮件不在窗口中或属于其他目录，记录历史不完整，不能据此宣称完整会话已读取。
5. 重复 read，确认同一身份使用相同快照目录。全过程不发送、不移动、不删除邮件。
